## ภาพรวมโปรเจกต์: Phase 2 กับ Phase 3 ต่างกันอย่างไร?

ข้อมูลหลังทำความสะอาดมีทั้งหมด **6,425 ห้อง จาก 230 โครงการ** แบ่งชุดข้อมูลตาม `project_id` เพื่อไม่ให้ห้องในคอนโดเดียวกันซ้ำข้ามชุด (`Train 4,217 ห้อง / 138 โครงการ`, `Validation 1,408 ห้อง / 46 โครงการ`, `Test 800 ห้อง / 46 โครงการ`)

* **Phase 2 (Baseline — 18 ตัวแปรเฉพาะข้อมูลภายในห้อง):**
  * ใช้ข้อมูลจากตาราง `Room` ได้แก่ ขนาดพื้นที่ (`log_size`), ชั้น, จำนวนห้องนอน, ประเภทห้อง, ห้อง 2 ชั้น (`is_duplex`), จำนวนของใช้ในห้องรวม และรายการสิ่งอำนวยความสะดวกภายในห้อง 12 รายการ
  * เปรียบเทียบ 4 อัลกอริทึมบนชุด Validation ได้แก่ `Median Baseline`, `Ridge Regression`, `Random Forest` และ `HistGradientBoosting` พบว่า **`Ridge Regression` (แปลงเป้าหมายด้วย $\ln(1 + \text{rental})$)** ทำผลงานดีที่สุด
  * **ข้อจำกัดที่พบ:** การดูเฉพาะสภาพภายในห้องทำให้แยกความแตกต่างของทำเลและเกรดโครงการไม่ได้
* **Phase 3 (Improved — 24 ตัวแปร: 18 ข้อมูลห้อง + 6 ข้อมูลโครงการ):**
  * เชื่อมข้อมูลจากตาราง `Project` ด้วย `project_id` เพื่อเพิ่มคุณลักษณะระดับโครงการอีก **6 ตัวแปร** ได้แก่ **เขตที่ตั้ง (`project_district`)**, **จำนวนยูนิตทั้งโครงการ (`log_project_units`)**, **อายุอาคาร ณ ปี 2023 (`project_age_2023`)**, **จำนวนอาคาร**, **จำนวนชั้นสูงสุด** และ **จำนวนส่วนกลางโครงการ (0–20 รายการ)**
  * ใช้ `Ridge Regression` ฝึกบน `Train + Validation` (5,625 ห้อง) แล้วทดสอบบน **Test Set 800 ห้องเดิม**

| โมเดล (ทดสอบบน Test Set 800 ห้อง) | จำนวนตัวแปร | MAE (บาท/เดือน) | RMSE (บาท/เดือน) | $R^2$ | ทายใกล้เคียง (±20%) |
| :--- | :---: | ---: | ---: | :---: | :---: |
| **Phase 2 (เฉพาะข้อมูลห้อง)** | 18 | 13,866.36 | 29,879.92 | 0.7089 | 31.38% |
| **Phase 3 (18 ห้อง + 6 โครงการ)** | **24** | **10,013.88** | **24,660.18** | **0.8017** | **69.50%** |
